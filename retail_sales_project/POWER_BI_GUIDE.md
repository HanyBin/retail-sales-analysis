# Инструкция: дашборд в Power BI за 20 минут

## 1. Установка
- Скачай **Power BI Desktop** бесплатно: https://powerbi.microsoft.com/desktop/
- Установи, запусти, войди с аккаунтом Microsoft (можно бесплатный)

## 2. Загрузка данных
1. Открой Power BI Desktop
2. Нажми **«Получить данные»** → **«Текст/CSV»**
3. Выбери файл `output/sales_summary_for_powerbi.csv`
4. В появившемся окне убедись, что кодировка **UTF-8** и столбцы распознались
5. Нажми **«Загрузить»**

## 3. Создание дашборда

### Карточки с KPI (верхняя полоса):
1. На панели «Визуализации» справа нажми **«Карточка»**
2. Перетащи поле `revenue` → появится сумма выручки
3. Повтори для `profit`, `orders`, `qty`
4. Расположи 4 карточки в ряд сверху

### График 1: Выручка по месяцам (линейный)
1. Нажми **«Линейная диаграмма»**
2. Ось X → `year` + `month`
3. Значения → `revenue` (сумма)
4. Добавь вторую линию: `profit`

### График 2: Выручка по регионам (столбчатый)
1. Нажми **«Гистограмма с группировкой»**
2. Ось → `region`
3. Значения → `revenue` (сумма)
4. Отсортируй по убыванию (три точки → «Сортировка по revenue»)

### График 3: Доля категорий (кольцевая)
1. Нажми **«Кольцевая диаграмма»**
2. Легенда → `category`
3. Значения → `revenue` (сумма)

### График 4: Таблица с деталями
1. Нажми **«Таблица»**
2. Добавь столбцы: `region`, `category`, `revenue`, `profit`, `orders`

### Фильтр по году:
1. Нажми **«Срез»** (Slicer)
2. Поле → `year`
3. Теперь можно переключать года — все графики обновятся

## 4. Оформление
1. Вкладка **«Формат»** → выбери тему (рекомендую нейтральную)
2. Добавь заголовок страницы: **«Анализ розничных продаж»**
3. Подровняй элементы по сетке

## 5. Сохранение
1. **Файл → Сохранить** → `retail_sales_dashboard.pbix`
2. Для скриншота в портфолио: **Файл → Экспорт → PDF**

## Результат
У тебя получится интерактивный дашборд с 4 графиками,
KPI-карточками и фильтром по годам. Скриншот → в README на GitHub.
